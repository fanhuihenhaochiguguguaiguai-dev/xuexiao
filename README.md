# 河南经贸职业学院 · 官方扫描源独立校园漫游工程

**状态：独立可运行的手机 Web 3D 漫游程序与严格的数据验收门禁；尚不是完整的真实校园 3D 复刻。**

## 重要约束

- 校园只使用用户指定的官方 VR 全景来源：<https://www.ivrpano.com/p/2b89e1f8b87d40ad>，以及由合法取得的官方扫描资料衍生、并有验证记录的模型。
- **不引用、不复制、不融合**此前用户独立制作的 `HenanCampus.blend`、`HenanCampus.glb`、OSM 推测楼体、自动程序化楼群或其他 `xuexiao` 资产。
- 初始页面是**人物操作测试区**（一张无建筑的网格地面），不是复刻学校；演示人物只是控制器样机。
- 官方网站提供可浏览的 360° 全景，不意味着向公众提供原始网格/深度图。此前记录：54 个不同机位、324 张立方体面图片、238 条导航关系；这些**历史记录**没有被再次抓取，也没有在此项目里重复上传。
- 本工程不绕过授权、不破解私有资源、不把无许可的素材传到公开 GitHub。

## 已实现

- WebGL 手机端 3D 第三人称角色，左侧虚拟摇杆、右侧镜头拖动、WASD/方向键、行走动画、镜头重置。
- 场景选择，机位切换，支持 360° 全景图片（等距柱状图）和六面 Cube 图片（需确认官方面序）。
- 支持合法获取的扫描 `.glb` 进入同一场景，简单的网格射线探测（实验性，不等于完整物理导航）。
- 支持导入场景清单 `manifest.json`，选择本地官方素材预览（手机浏览器内存中加载、不会自动上传）。
- 明确标示「全景照片」与「真实 3D 网格」两种不同的数据等级。
- 一套 `scripts/scan_gate.py` 的三维重建前置检查与 `scripts/validate_official_data.py` 的资源清单验证。
- GitHub Actions 验证工作流模板（在独立仓库根目录部署时生效）。

## 如何打开

把项目放到支持 HTTPS 的静态托管（GitHub Pages、Cloudflare Pages 均可），打开 `index.html` 即可。加载 Three.js 时需要联网访问 jsDelivr。由于 ES Modules/CORS 要求，不推荐在手机文件管理器直接 `file://` 双击页面。

本地调试：

```bash
python3 -m http.server 8080
```

浏览器打开 `http://localhost:8080`。手机端可用触控摇杆。

## 从官方全景到真正可行走的全校复刻

1. **取得原始数据**：请学校或制作方提供经授权的 GLB、FBX、OBJ、点云、深度图、或者带相机姿态的重叠原始照片。仅网页上显示的立方体全景不等于原始扫描文件。
2. **摄影测量可行性分析**：每个全景点是一个机位，6 张方图不是 6 个独立机位；检查**不同机位之间**重叠特征、曝光、相机姿态和尺度是否充分。只有条件满足再使用 COLMAP / OpenSfM 等软件在云主机上重建；手机不需要下载与运算大型模型。
3. **重建 + 验证**：从稀疏点云到稠密网格、几何空洞填补、贴图、优化 LOD、真实比例和可步行导航碰撞分别验收。不能凭空补全未拍到的建筑背面、室内和盲区，并声称百分百复刻。
4. **导入本程序**：在官方原始模型或真实重建结果得到验证后，填写 `manifest.json`，角色才进入真实扫描场景。
5. **全校覆盖**：逐区域重复，保留未覆盖范围、误差与来源清单。版权和地理坐标准确性独立验证。

## 现在还缺什么

此运行环境无法从指定 `ivrpano.com` 网页拿到页面文件或官方模型；没有提供原始扫描数据、逐机位图像、位姿和深度。因此**不可能在此交付整校精确扫描三维模型**。本交付是可以立即运行和继续接入数据的独立程序，不是已经完成的全校游戏。

安全原则：不枚举未授权隐藏端点、不突破 401/403/登录权限、不公开传播未许可的学校全景版权素材。
