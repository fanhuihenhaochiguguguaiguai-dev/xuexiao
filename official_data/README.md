# 官方素材放置位置

本目录不附带第三方全景影像或网站代码，避免未经许可复制、重新分发。

可将有权使用的学校官方全景 JPG 和真实扫描 GLB 放置于此，然后在 `manifest.json` 中登记每个机位与来源。
支持：

- `panorama`: 单张 360° 等距柱状全景 JPG/PNG（比例约 2:1）；
- `cube_faces`: 按 +X,-X,+Y,-Y,+Z,-Z 顺序的 6 张方图（须确认官方切片方向后使用）；
- `scan_glb`: 实际扫描/重建并核实的 .glb 模型；
- `links`: 机位之间的合法导航关系，不等于实际可步行的几何道路。

如果只有照片而没有扫描网格，展示属于“全景漫游”，不宣称实现真实3D复刻。
