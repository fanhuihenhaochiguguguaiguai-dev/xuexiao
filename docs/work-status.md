# 当前工作状态：v0.6

唯一正式仓库为 xuexiao；v0.6已合并主线并成功发布至原Site，已按用户要求开放公开试玩（2026-10-27），无需所有者账号。部署追溯见 reports/web-deployment.json。每阶段获取远程、检查、提交推送；本次云环境重启后已恢复每分钟同步进程。

## 本轮已完成的实现

- 石桥桥面/开孔栏杆/桥头过渡与碰撞；12级图书馆入口台阶、独立基座与3米楼面网格；体育场观礼平台、接地台阶、护栏和可步行看台通道。实际Rapier检查记录见 v06-interactions.json。
- 图书馆九层资料交叉核对；主体27米与1.8米基座分别计。20处现有建筑按米制布局，未取得的实测尺寸仍不宣称1:1。
- 三处水域去除阻挡，地面挖空，生成估算湖床；涉水、浮力/阻力、浮水/游泳动作、出入岸与接触波纹。人物复用原网格与4段动作，增加2段水中动作及服装/头发材质调整。
- 实际绘图缓冲1.25–1.5倍超采样；2048px、2级CSM、PCF5和可选PCSS；TAA邻域夹取、运动自适应、历史重置及人物/水面反应区域，0.22锐化。
- 自制HDR天空与IBL，半分辨率SSAO、HDR Bloom、色彩分级和可选体积雾；多尺度水纹、折射、岸泡及局部HDR反射。逐面刷新按帧耗时控制，初始化超时可以补齐。
- 4096px自制PBR源图；运行时1K/2K预算和无损WebP部分传输；20处楼群细节分区，190米加载、250米卸载，远处及离线保留基础实体。
- 实际2048px/16采样Cycles AO及4096px静态投影源图。GLB/FBX实际重新导入，20处建筑索引、闭合主体、纹理及1毫米导出一致性检查通过。

当前浏览器验证与发布进度以 reports/v06-browser.json、playable-regression.json、browser-device-check.json、web-deployment.json 中的版本与源哈希为准。不得将历史报告当作最新测试。51项自动测试由34项Python、8项Rapier移动/水域、9项性能判定组成。
