# 校园探索体验试验：阶段结果与可迁移经验

本目录是独立试验，不是正式校园的新版本。正式 `xuexiao/main` 的代码、模型、Site身份与权限均未改动。新建GitHub仓库被当前集成授权拒绝，因此保存到同仓库独立实验分支 `experiments/campus-exploration-lab`，不向main合并。

## 已证实的体验改进

| 原有瓶颈 | 本次最小改变 | 实际证据与边界 |
|---|---|---|
| 地图地点只能切换出生点，缺少连贯步行探索 | 复用Rapier碰撞，生成保守通行网格；A*规划、路径简化、同一人物控制器自动转向/行走 | 四地点12条有向路线均实际碰撞步行到达；无传送。四站浏览器整圈、到站继续与楼外接近也通过 |
| 导览与自由漫游相互割裂 | 输入事件立即暂停导览；保留目的地、从当前位置重规划继续；到站可查看说明 | 真实键盘/浏览器触控、暂停/继续、到达提示及建筑点击通过。不是手机真机验收 |
| 首次进入默认占用45秒检测 | 将检测保留为用户自选，不阻挡第一次探索 | 进入直接漫游，仍可打开原有真实postrender检测和导出报告 |
| 竖屏被强制旋转挡住 | 可玩的竖屏布局；地点面板选中后收起，避免遮挡下一步按钮 | 393×852真实浏览器视口和原生触控事件通过；不是实体安卓设备 |
| 固定分辨率无法反映设备负载 | 根据真实postrender帧间隔调整0.75–1.25分辨率与局部阴影；降档与升档使用不同门槛 | 控制器边界与迟滞检查通过。未证明手机帧率、温升或功耗收益 |
| 云端软件WebGPU信息未正确识别、队列积压 | 显式读取GPUAdapterInfo字段；仅软件设备等待GPU队列再提交画面 | PlayCanvas2.23.3带窗口软件WebGPU实际校园/人物画面、互动与导览通过；硬件路径保留正常帧循环 |
| 资源清单已落后于实际GLB | 复用真实模型哈希，重建清单，并核对碰撞导航的来源哈希 | 27项资产真实哈希通过；原校园、人物、world字节不变，无重建和重新导入 |

新增路线由一个网格文件、一个导览状态机和轻量UI模块构成，没有升级引擎或重做模型。网格约24.5万格、11.7万通行格，首次生成约0.5秒；同输入跳过。3D路线为同一个批量网格，切换后释放；12次切换实际没有累积路线实体。

## 真实来源与原站

- 原始模型/碰撞/人物保留自 `42db0677d3fbd961763bd9f5d70376c5695f229a`，实际文件哈希见 `reports/baseline.json`。
- 用户提供全景地址已实际打开，标题为“河南经贸职业学院VR校园全景漫游_校园南门”。页面/Canvas存在不等于全景照片可见；测试等待原站加载遮罩结束并检查实际画面差异，结果见 `reports/reference-viewer.json`。
- 原站全景作为独立实景参考打开，不将照片贴成伪造3D校园，不复制原始照片到仓库。实验中的“南侧办公楼前”不是已校准的全景校门坐标。
- 地图为OSM来源近似模型；楼层、高度、部分建筑身份及人物细节仍有估算。缺失结构、平面配准和逐楼精度问题没有因本试验而被标记完成。

## 验证范围

`reports/webgpu-desktop.json`、`webgl2-mobile.json`、`auto-fallback-portrait.json`记录浏览器体验；`reports/interaction.json`记录四站导览、实际建筑几何点击、楼外步行和资源清理。WebGPU不可用时自动降级为WebGL2并明确显示后端。设备性能仍只能由用户手机打开测试站后自测，云端软件渲染不充作手机FPS通过。

原有模型、碰撞数据和已通过模块不重做。本轮新18项Node检查覆盖寻路/物理闭环、空闲状态、暂停继续、通行边界、导览及画质迟滞；源码与输入哈希留档。未重跑54个全景站或批量220项请求。

## 可复用与保存

- `npm ci && npm test && npm run build`；模型未变，不需Blender或导出流程。
- `npm run build:nav` 仅当碰撞源变化时生成；现有输入命中则跳过。
- `python3 tools/verify_assets.py` 检查真实字节；显式 `--write-manifest` 才更新清单。
- `tools/sync_progress.py` 原样复用既有验证过的同步引擎；先begin，阶段通过后checkpoint。本云环境watcher每分钟检查远端，只推送已有验证提交，不提交未完成编辑；冲突保留、禁强推。环境停止后不承诺继续运行。
- 新测试Site保持所有者访问，与正式校园原Site分开。当前环境未带Sites本地辅助脚本，发布使用官方工具返回的短期源仓库凭据，经隐藏stdin传递，普通Git及可校验静态归档完成；不在文件/命令行/日志保存令牌。
