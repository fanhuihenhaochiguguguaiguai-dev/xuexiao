# 国内访问与静态部署

这是同一份游戏的发布文件，不是另一套工程。解压后的 index.html、game.js、assets/、sw.js 等文件放到网站根目录，以 HTTPS 提供访问。WebGPU 不可用时自动改用 WebGL2。

游戏程序、引擎转换器、WASM、场景、模型、纹理和字体均无需访问海外 CDN。实际浏览器网络检查见 reports/v07-browser.json。运行资源包不包含用户原始参考照片。GLB 已嵌入所需基础纹理；精细分区加载失败时保留基础楼体。

可使用已授权的百度智能云 BOS 或其他支持 HTTPS 的静态网站托管。对象的 MIME 类型至少正确设置 HTML、JavaScript、JSON、WebAssembly、PNG、WebP；建议使用示例 nginx 配置中的类型。模型以二进制提供，不能被 SPA 的 index.html 错误替代。部署于域名根目录，保留大小写和目录结构。

## 本轮实际检查结果（2026-10-27）

- 百度智能云 BOS 产品页正常公开访问：https://cloud.baidu.com/product/bos.html 。当前云环境没有百度云授权、存储桶或网站域名，未创建付费资源。
- 百度搜索资源平台正常公开访问：https://ziyuan.baidu.com/ 。它提供搜索收录管理；收录不等同于游戏托管，也不能保证特定网址在国内连通。
- GitHub 仓库授权可提交、推送源码。查询确认尚未启用 Pages；开通接口实际返回 HTTP 403 `Resource not accessible by integration`，当前集成没有此项权限。本轮没有绕过权限，也未伪造备用网址。
- 原 Sites 网址已保持公开，但没有中国大陆网络测点，不能证明它在国内各运营商可用。

## 剩余阻碍与最小下一步

国内上线仍需一个已授权的 HTTPS 托管目标。获得该账户授权和可用域名后，由 AI 上传此部署包、检查所有资源与缓存更新，再从大陆移动/联通/电信网络验证。用户无需编程、安装开发工具或逐个上传文件。

百度收录需要站点所有权验证；取得域名后再设置 sitemap 和收录提交。当前没有把“百度可搜索”或“中国大陆已通过访问验收”标记为完成。
