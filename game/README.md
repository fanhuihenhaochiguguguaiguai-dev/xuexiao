# 河南经贸3D数字校园 v0.6：横屏PWA

现有唯一正式游戏源码，PlayCanvas2.23.3、Rapier0.21.0，默认WebGPU优先并兼容WebGL2。网页版继续使用原Site和原访问权限。

本版补充石桥、12级图书馆入口台阶、体育场观礼平台与细分看台通道；移除水域阻挡，加入岸距估算湖床、浮力/阻力、游泳/浮水动画与接触波纹。人物约1.701米，外貌仍为参考图引导近似。

按每层3米组织楼面；图书馆九层主体27米，入口基座1.8米另计。楼群平面采用OSM，桥位、水深、平台和台阶尺寸仍估计，尚非测绘级1:1，也没有完整校园与室内全部开放。

真实绘图缓冲超采样1.25–1.5，TAA/适度锐化与反应区域，2048px双级CSM，PCF5与可选PCSS；HDR天空、IBL、半分辨率SSAO、Bloom和可选体积雾。水面加入折射及局部HDR Cubemap动态刷新，超预算暂停。贴图1K/2K预算，20个楼群细节分区加载，远处保持基础实体。高精贴图部分采用无损WebP传输；GPU块压缩尚未接入。

dist为当前构建产物；PWA支持横屏、桌面入口和基础资源离线重载。原始source模型在assets/henan_campus目录。AI负责构建、验证和阶段GitHub同步，用户无需安装开发工具。当前证据与未完成项见仓库docs/v06-validation.md；实体安卓WebGPU与帧率仍需手机报告，本轮不打包APK。
