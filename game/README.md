# 河南经贸3D数字校园：横屏PWA局部精修版

当前唯一浏览器游戏源码目录，继续使用原私有站点及同一工程，`dist/`为当前构建输出。PlayCanvas固定2.23.3，Rapier固定0.21.0，默认优先WebGPU并兼容WebGL 2。

本轮集中整改图书馆南广场：按缓存的2017年照片制作横向蓝色窗带、浅色立柱、弧形挑檐、立体名称、入口台阶与铺装。其他区域继续保留原有草模；所有新增垂直尺寸仍为估算。

人物服装改为独立蒙皮网格，保留17根骨骼和4段动画；整体约4.46万三角面。面部、头发和服装细节仍是近似，不是照片级角色。

新增manifest、桌面图标、安装入口和Service Worker。应用以独立窗口横屏运行，普通浏览器竖屏时提示旋转手机。全屏、安装和方向锁定由设备浏览器授权；当前未生成APK。`dist/pwa.js`负责安装与方向请求，`dist/sw.js`负责受限制的同源资源缓存，不缓存认证跳转和不可缓存响应。

本地手机横屏触控、地图复位、人物骨骼、台阶、建筑碰撞和断网重新加载已验证，普通浏览器安装条件检查0错误。实体安卓安装、硬件WebGPU与真实手机帧率尚未验证。云端软件渲染帧率不满足流畅验收。

开发命令由AI执行：`npm ci`、`npm run build`、`npm run check:physics`。当前源资产已集中保存在仓库的`assets/henan_campus/`，统一调度脚本位于`automation/`；用户无需编程或手工建模。详细结果见验收报告.md及qa目录。
