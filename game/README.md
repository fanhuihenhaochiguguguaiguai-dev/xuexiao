# 河南经贸3D数字校园 v0.7：横屏PWA

现有唯一正式游戏源码，PlayCanvas2.23.3、Rapier0.21.0，默认WebGPU优先并兼容WebGL2。网页版继续使用原公开Site。

本版补充石桥、12级图书馆入口台阶、体育场观礼平台与细分看台通道；移除水域阻挡，加入岸距估算湖床、浮力/阻力、游泳/浮水动画与接触波纹。人物约1.701米，外貌仍为参考图引导近似。

按每层3.9米组织常规楼面；图书馆九层主体35.1米，入口基座1.8米另计。楼群平面采用OSM，桥位、水深、平台和台阶尺寸仍估计，尚非测绘级1:1，也没有完整校园与室内全部开放。

默认实际渲染比例1.0、1024px单级CSM/PCF3、手机30FPS上限目标，保留TAA与锐化；可选1.25/1.5高档。默认关闭SSAO、Bloom、体积雾、水面折射与局部动态刷新，保留基础HDR反射和多尺度波纹。精细楼群默认最多6处，远处保持基础实体。GPU块压缩尚未接入。
dist为当前构建产物；PWA支持横屏、桌面入口和基础资源离线重载。原始source模型在assets/henan_campus目录。AI负责构建、验证和阶段GitHub同步，用户无需安装开发工具。当前证据与未完成项见仓库docs/v07-validation.md；实体安卓WebGPU与帧率仍需手机报告，本轮不打包APK。
